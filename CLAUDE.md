Read `AGENTS.md` before doing anything in this folder. It explains how to turn someone's text into `talk.md`, the rules for good slides, the file format, and the commands.

The short version: write `talk.md`, put pictures in `media/`, run `npm run check` until it says "Ready to present", then run `npm start`. Leave `engine/` alone unless the person asks for an engine change, and run `npm test` after any such change.
